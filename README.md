# Java Day 17 - Month Name

## Description

This program uses the `switch` statement to display the month name based on the month number entered by the user.

The user enters a number from 1 to 12, and the program displays the corresponding month.

## Example

```text
Enter month number (1-12): 8
August
```

## Month Numbers

| Number | Month     |
| ------ | --------- |
| 1      | January   |
| 2      | February  |
| 3      | March     |
| 4      | April     |
| 5      | May       |
| 6      | June      |
| 7      | July      |
| 8      | August    |
| 9      | September |
| 10     | October   |
| 11     | November  |
| 12     | December  |

## Concepts Used

* Scanner
* User Input
* switch statement
* case
* break
* default
* int

## How It Works

1. The program asks the user to enter a month number from 1 to 12.
2. The number is stored in the `month` variable.
3. The `switch` statement checks the value of `month`.
4. The matching `case` displays the month name.
5. `break` stops the switch statement.
6. If the number is not between 1 and 12, the `default` case displays an error message.

## File Name

`Main.java`

## Goal

The goal of this program is to practice the `switch` statement with multiple cases and user input.
